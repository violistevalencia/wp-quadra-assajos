# wp-quadra-assajos

Plugin de WordPress **«Programant Haydn: Les set últimes paraules de Crist a la creu»** — Quadra d'assajos del quartet.

Planificador d'estil Doodle per quadrar les agendes dels músics: cada músic marca els dies i hores disponibles i el calendari mostra les millors coincidències, amb el concert del 27 de febrer destacat com a data inamovible.

## Instal·lació ràpida

1. Descarrega aquest repositori (**Code → Download ZIP**) i extreu-lo.
2. A WordPress: **Extensions → Afegeix nova → Puja extensió** i puja el ZIP corresponent a la carpeta `quartet-scheduler/`.
3. Activa'l i configura'l al menú **Quadra assajos**.

Tots els detalls d'ús, dins de la carpeta del plugin al [README del plugin](quartet-scheduler/README.md).
